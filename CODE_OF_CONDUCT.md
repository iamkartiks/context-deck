# Code of Conduct

ContextDeck is built by people with different backgrounds, experience levels and opinions about which coding agent is best. We want everyone to feel welcome contributing.

## Expected

- Be kind and assume good intent. Most friction is a misunderstanding.
- Critique code and ideas, not people.
- Help newcomers; everyone's first adapter was messy.
- Respect privacy: never post someone's transcripts, code or paths without their permission.

## Not acceptable

- Harassment, insults, or discriminatory language or imagery.
- Personal attacks or sustained disruption of discussions.
- Publishing others' private information.
- Sexualised language or imagery.

## Enforcement

Maintainers may edit or remove comments, commits and issues that break this code, and may temporarily or permanently ban contributors for serious or repeated violations. Report problems privately to the maintainers (use the contact listed on the repository profile); reports are handled confidentially.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), which you can read for more detail.
